# meal-scheduler
# 🍞 飯食服事自動排班系統 (Meal Service Auto-Scheduler)

本系統專為學期飯食服事排班設計，結合 **Google OR-Tools (CP-SAT Solver)** 數學最佳化演算法與 **Streamlit** Web 視覺化介面。
能自動讀取 Google 表單原始回覆（支援 CSV 與 Excel），在數秒內計算出完全符合性別限制、離台日期、個人次數微調，且達成極致公平（權重積分標準差最小化）與最大化個人偏好的彩色 Excel 排班表。

---

## 🌟 核心排班邏輯與約束條件 (Scheduling Rules)

### 1. 硬性約束 (Hard Constraints - 必須完全滿足)
* **飯前服事**：每時段固定 **2 人**，且 **性別必須完全相同**（全弟兄或全姊妹）。
* **飯後服事**：每時段 **4 ～ 5 人**（性別不限）。
* **飯後配搭防呆**：飯後時段任一性別（弟兄或姊妹）人數 **不可剛好為 1 人**（允許 0 人或 2 人以上，避免單獨落單）。
* **單日限制**：每人每天最多只能排 **1 個時段**（不可當天同時服事飯前與飯後）。
* **請假與出缺勤**：
  * 尊重成員於表單填寫的可服事意願，未勾選或標示無法出席的時段絕對不排。
  * 嚴格遵守成員的 **提前離台日期**（離台後不排班）與 **延後加入日期**（加入前不排班）。
  * 國定假日與學期不排班日期自動剔除。

### 2. 彈性微調與軟性目標 (Soft Objectives)
* **個人次數微調 (Custom Adjustments)**：
  * 管理者可在介面上直接設定特定人員「減少特定次數」（如：某人少排 1 次飯後）。
  * 系統內部內建 **「虛擬積分補償機制」**，確保該成員總權重確實下降，演算法絕對不會「拿飯前補飯後」或拉低全體平均。
* **極致公平性 (Weight Fairness)**：
  * 權重積分計算：**飯前服事 = 2 分**，**飯後服事 = 1 分**。
  * 演算法目標：**極小化全學期最高積分與最低積分的差距**，確保每位成員的服事負擔均等。
* **個人偏好滿足 (Preference Satisfaction)**：
  * 優先安排成員於表單中勾選「偏好」的星期與時段。

## 🚀 快速使用指南 (Quick Start Guide)

### 步驟 1：取得 Google 表單回應
1. 開啟該學期的 Google 排班調查表單。
2. 切換至「回應 (Responses)」頁籤，將結果匯出下載（支援 `.csv` 或是 Google 試算表下載為 `.xlsx` 皆可）。

### 步驟 2：開啟雲端網頁與操作
1. 開啟本系統專屬雲端網頁連結。
2. **上傳檔案**：在網頁左側邊欄拖曳上傳剛下載的表單檔案。
3. **調整學期參數**：確認/修改「學期開始/結束日期」、「國定假日」、「每週服事星期」與「人數需求」。
4. **設定特殊排班**：選取該學期有「提前離台」、「延後加入」或需要「次數微調（少排班）」的成員並完成設定。
5. **生成與下載**：點擊 **「🚀 開始自動排班」** 按鈕，計算完成後點擊 **「📥 下載彩色版排班 Excel 檔案」**。

## 📁 產出 Excel 結構說明 (Excel Output Structure)

產出的 Excel 檔案包含兩個工作表（Tabs）：
1. **`排班總表`**：
   * 採用與傳統試算表一致的視覺樣式（週別、日期、飯前橘底、飯後黃底、表格邊框）。
   * 依據使用者勾選的排班天數，按週劃分清晰呈現每日的飯前與飯後服事名單。
2. **`個人權重統計`**：
   * 統計每位成員全學期的 **飯前次數 (2分)**、**飯後次數 (1分)** 與 **總權重積分**。
   * 提供 **偏好滿足次數** 統計，方便管理者核對與向團隊公布排班公平性。
